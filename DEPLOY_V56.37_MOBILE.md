# Cập nhật V56.37 (mobile)
1. Sao lưu Worker và D1 hiện tại trước khi deploy.
2. Giải nén ZIP, cập nhật các static assets theo cấu trúc đang dùng và deploy Worker.
3. Migration thêm cột `video_url` là additive; không xóa dữ liệu.
4. Vào Admin chính → File/Code → Tag → tạo/sửa tag và dán link YouTube. Admin tenant → Nội dung → Tag → dán link lúc tạo tag.
5. File phải có trường tag/game khớp tên tag để video hiện ở cuối trang chi tiết.
6. Mở site chính và tenant trên điện thoại kiểm tra. Link video để trống thì không hiển thị khung video.
7. Video đăng ký tài khoản và các lỗi AI/ảnh báo lỗi/đơn hàng/preview còn cần xử lý tiếp, không xem đây là bản sửa toàn bộ.
