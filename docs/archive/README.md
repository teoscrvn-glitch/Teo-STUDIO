# TeoStudio archive

Tài liệu lịch sử và JavaScript Admin cũ được giữ nguyên nội dung tại đây để tra cứu.

- `release-history/`: changelog, deploy guide, version note và test report cũ.
- `html-guides/`: hướng dẫn HTML cũ; `index.html` ở root được giữ cho GitHub Pages legacy.
- `legacy-admin-js/`: `admin-v7.js` đến `admin-v13.js`; đã quét `frontend/**/*.html` và không có thẻ script nào tham chiếu các file này.

Cloudflare Worker đang publish thư mục `frontend/` theo `cloudflare/wrangler.toml`; archive không nằm trong asset bundle production.
