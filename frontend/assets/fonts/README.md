# Be Vietnam Pro — self-hosted font dependency

The V60.3 archive and Redesign Kit supplied for this task contain no WOFF2 font binaries. No remote Google Fonts request or broken local `@font-face` declaration was added.

Expected files when the font assets are added: `BeVietnamPro-Regular.woff2`, `BeVietnamPro-Medium.woff2`, `BeVietnamPro-SemiBold.woff2`, `BeVietnamPro-Bold.woff2`, and `BeVietnamPro-ExtraBold.woff2` (each should be checked against the brief size target).

Upstream source: https://github.com/bettergui/BeVietnamPro/tree/main/fonts/webfonts
License metadata: Google Fonts records Be Vietnam Pro under the SIL Open Font License (OFL). Verify and copy the upstream `OFL.txt` alongside the font binaries before shipping them.
