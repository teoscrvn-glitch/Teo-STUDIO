# TeoStudio Share UI — Bản xem trước

Mở `index.html` để xem tương tác chọn mẫu trong trình duyệt. `preview-contact-sheet.png` là ảnh tổng hợp để xem nhanh.

Các mẫu:
1. **Sakura Glow** — anime, gradient tím hồng, banner lớn.
2. **Tiger Neon** — gaming/cyber, tông xanh tím.
3. **Cloud Minimal** — sáng, ít hiệu ứng, ưu tiên dễ đọc.
4. **Pixel Arcade** — retro neon, thích hợp kho game/script.

Ảnh minh họa và logo SVG trong `assets/` được làm riêng cho bộ concept này. Các nút trong gallery chỉ đánh dấu lựa chọn trong trang demo. Thư mục này nằm ngoài `frontend/`, không tự động tích hợp hoặc deploy vào website chính. Cần duyệt một mẫu trước khi áp dụng.
