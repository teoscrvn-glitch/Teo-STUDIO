# V60.9 merge notes

## Base
V60.8 is the base. V60.9 is a frontend-focused patch and retains existing API/Worker/D1/auth/payment logic.

## Catalog
The same `#productGrid` renderer is used by the main homepage, legacy `/2`, and tenant Share. The mobile catalog stylesheet is now loaded by all three. Phone and coarse-pointer viewports use two columns; desktop uses three. The body content is explicitly visible and the thumbnail ratio is bounded.

## Sales ticker
The recent-sales feed is generated by `account.js` as a duplicated horizontal track. V60.9 overrides the older responsive `display:contents` rules so it remains a ticker on mobile/coarse screens, moves left-to-right, and cycles a restrained border glow. Reduced-motion users do not receive continuous animation.

## Navigation
The shared router intercepts leaderboard links only; ordinary navigation remains native. Leaderboard opens in a same-document overlay and adds a history hash without replacing the parent path or query. Tenant/Studio/AI context is allowlisted and copied to internal same-origin destinations. Account pages receive a safe return URL so the account Back/brand links can return to the source Share/Admin/detail route.

## Safety and limits
No payment, API or D1 logic was changed. Static build and parity checks pass, but the repository-wide design linter still reports legacy `!important` and color debt. Real-device screenshots and production API/D1 behavior were not verified.
