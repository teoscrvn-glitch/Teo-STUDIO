# TeoStudio V56.3

A stabilization build based on V56.2 with visible build fingerprint, safe runtime configuration diagnostics, an Admin Runtime Check panel, and manual test buttons for AI, email and Telegram.

Start with `DEPLOY_V56_3_MOBILE.md`, then consult `VERSION_V56_3.md` and `TEST_REPORT_V56_3.md`. Archive paths `cloudflare/` and `frontend/` are at the ZIP root to reduce the risk of copying the wrong nested file.
